# Milestone 1 — Core Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A running wiremock-ui backend that stores every mock in Redis, pushes it to a basic-auth-protected WireMock 3, and rebuilds WireMock from Redis automatically after a WireMock restart.

**Architecture:** One TanStack Start app (TypeScript). All logic lives in plain modules under `src/server/` (config, WireMock admin client, Redis store, mock service, reconciler) that take their dependencies as arguments and are tested with Vitest against real WireMock and Redis containers (Testcontainers). TanStack Start server routes under `src/routes/api/` and `src/routes/healthz.ts` are thin adapters that call `src/server/http/*` handlers through a lazily started runtime singleton.

**Tech Stack:** Node 22, TypeScript (strict), TanStack Start (React) with server routes, `ioredis`, `zod`, `pino`, Vitest, `testcontainers`, Docker Compose, `wiremock/wiremock:3.13.1`, `redis:7.4-alpine`.

**Spec:** `docs/spec.md` — read "Storage and sync", "Configuration, images and deployment", "Security" and the **Amendments** section (A1 batch sync, A2 rollback, A3 M1 API auth) before starting.

## Global Constraints

- WireMock image pinned to `wiremock/wiremock:3.13.1`; UI refuses WireMock with major version `< 3`, message: `WireMock 3.x is required, found <version>`.
- Every stub written to WireMock has `persistent: false`.
- Response bodies are inline only; a stub with `response.bodyFileName` is rejected with `400` and message `bodyFileName is not supported; put the body inline`.
- Stub metadata key is `metadata.wiremockUi` with fields `{integration, endpoint, owner, version, updatedAt, updatedBy, source}`.
- Redis keys exactly: `stub:{id}`, `stub:{id}:history`, `stubs:all`, `stubs:by-integration:{key}`, `stubs:by-owner:{user}`, `sync:lock`.
- History keeps the last 20 versions; after a delete, history expires in 7 days (604800 s).
- Full sync batch size 500; marker check every `SYNC_INTERVAL_SECONDS` (default 5); safety-net full sync every 600 s and at startup.
- Marker stub id `5e1f0000-0000-4000-8000-00000000c0de`, `request: {method: "GET", urlPath: "/__wiremock-ui/marker"}`, response `204`.
- Env defaults: `WIREMOCK_URL=http://localhost:8080`, `STORE_DRIVER=redis`, `SYNC_INTERVAL_SECONDS=5`; `ADMIN_USER`, `ADMIN_PASSWORD`, `SESSION_SECRET` required; `REDIS_URL` required when `STORE_DRIVER=redis`.
- UI listens on port 3000. Logs are JSON to stdout (pino).
- UI refuses to start if `GET /__admin/mappings` answers `200` without credentials.
- Licence: MIT.

## Review Focus

1. **Two people edit the same mock at once** — the second save gets `409` "changed by someone else"; WireMock keeps the first person's version. → Task 4, `concurrent edits`.
2. **Store holds more than 500 mocks when WireMock restarts** — all of them come back, not just the last batch (Amendment A1). → Task 5, `restores 1200 stubs`.
3. **Store write fails on an edit** — WireMock still serves the previous version; the mock is not deleted (Amendment A2). → Task 4, `rolls back edit`.
4. **WireMock restarts again in the middle of a full sync** — the marker is still missing afterwards, so the next check runs a full sync again. → Task 5, `marker only after success`.
5. **Two UI replicas notice the missing marker at the same moment** — only one runs the full sync; the other skips. → Task 5, `sync lock`.

  constructor(deps: { wiremock: WireMockClient; store: MockStore; now?: () => Date; newId?: () => string })
  create(input: MockInput, user: string): Promise<StubMapping>                        // version 1, owner = user, source 'ui'

Save algorithm (spec "Save" + Amendment A2):
1. Validate: reject `response.bodyFileName` (`ValidationError`, exact message from Global Constraints). Build the stub: `id`, `persistent: false`, merge `metadata.wiremockUi` = `{integration, endpoint, owner, version, updatedAt: now().toISOString(), updatedBy: user, source: 'ui'}`; keep any other metadata keys.
2. Update only: `previous = store.get(id)`; missing → `NotFoundError`; `previous.version !== expectedVersion` → `ConflictError` (before touching WireMock).
3. `wiremock.importStubs([stub], { deleteAllNotInImport: false })`. A `ValidationError` from WireMock propagates; nothing is stored.
4. `store.save(stub, expectedVersion)` (0 for create).
5. If step 4 throws: create → `wiremock.deleteStub(id)`; update → `wiremock.importStubs([await store.get(id) ?? previous], …)` (the store's current version, so a concurrent winner is what WireMock serves). Log rollback failures; rethrow the original error.

Delete: `get` → `NotFoundError` if missing; version check if given → `ConflictError`; `wiremock.deleteStub(id)`; `store.delete(id, expectedVersion)`.

### Task 5: Marker reconcile and full sync

**Files:**
- Create: `src/server/sync/marker.ts`, `src/server/sync/reconciler.ts`

**Interfaces:**

- Produces:

```ts
const MARKER_ID = '5e1f0000-0000-4000-8000-00000000c0de'
markerStub(): StubMapping            // GET urlPath /__wiremock-ui/marker → 204, persistent false, metadata.wiremockUi.source 'marker', owner 'system', version 1
class Reconciler {
  constructor(deps: { wiremock: WireMockClient; store: MockStore; intervalMs: number; safetyNetMs?: number /* default 600_000 */; batchSize?: number /* default 500 */ })
  check(): Promise<'ok' | 'synced' | 'skipped'>      // marker present → 'ok'; else fullSync()
  fullSync(): Promise<'synced' | 'skipped'>          // 'skipped' when sync:lock is held elsewhere
  start(): Promise<void>                             // runs fullSync() once, then check() every intervalMs and fullSync() every safetyNetMs
  stop(): void
  readonly lastSyncAt: Date | null
  readonly lastError: string | null
}
```

`fullSync` algorithm (Amendment A1): `acquireLock('sync:lock', 60_000)` → null ⇒ `'skipped'`. Then: `stubs = store.listAll()`; import in chunks of `batchSize` with `deleteAllNotInImport: false`; `liveIds = wiremock.listStubIds()`; `deleteStub` every live id not in the store (this includes the marker); import `markerStub()` **last**; set `lastSyncAt`; release lock in `finally`. Any thrown error → set `lastError`, log, release lock, rethrow from `fullSync` (the timer loop catches and logs). Timers must not overlap: skip a tick while a previous `check`/`fullSync` is still running.
